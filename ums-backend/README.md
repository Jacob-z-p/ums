## 相关经验

### 1. `Java record` 与 `Lombok`

在定义 DTO 这种实体类时，AI 在实现时给的方案是 `Java record` 这个记录类，虽然也能实现当下的功能。但是有几点问题：

- 扩展性差：如果要加一些字段，或者是对一些字段有限制，纪录类很难扩展。
- 不能修改：记录类通过 `final` 修饰，以为这不能多次 `set`，这对开发很不友好。
- 灵活性差：纪录类不能继承别类，也不能被别类继承

所以，从开发角度，还是直接定义实体类，然后用 `Lombok` 的相关注解就好（比如 `@Data`、`@AllArgsConstructor`、`@NoArgsConstructor`）。
